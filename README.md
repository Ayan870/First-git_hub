It's my first project at Superior University. It is a snake game like we had on the Nokia mobile. I have done this with simple concepts like loops, arrays, functions, etc. You can choose difficulty either easy or hard. In easy your snake will pass through the wall and emerge from the opposite wall but in hard the snake will die if it hits the wall. It covers the major basic concepts of language. It is a good project if you are a beginner in C++.
